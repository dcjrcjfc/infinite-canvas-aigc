# Infinite Canvas AIGC

节点式无限画布创作工作台。使用文本、图片、视频、音频和 3D 片场节点组织流程，上游文本进入下游提示词，直接连接的图片进入参考图。

框选或 Shift 多选后可分组、对齐、网格整理或按连线整理。拖动分组标题整体移动，双击重命名；节点和连线靠近画布边缘自动平移。右键提供节点/画布菜单；Ctrl+A 全选、Ctrl+D 创建副本、Ctrl+G 分组、Ctrl+Shift+G 取消分组。分组随项目保存并支持撤销。

仓库：https://github.com/dcjrcjfc/infinite-canvas-aigc

## 运行

需要 Node.js **22.16+**。运行服务只使用 Node 内置模块。浏览器使用已随源码保存的 Lucide 和 Three.js 构建产物；修改 `client/` 后运行 `npm ci` 和 `npm run build`。

```powershell
Copy-Item .env.example .env
# 编辑 .env：填写供应商密钥、完整模型 ID 和对应接口配置
npm start
```

访问 <http://127.0.0.1:8787>。Windows 和 Linux 使用相同入口。

从画布返回登录页：点击左侧工具栏最下方头像 → **返回登录首页**。离开前保存当前画布；保存失败会保留当前页面。登录首页也可直接访问 `/zh-CN/login`。

登录首页位于 `/zh-CN/login`（也支持 `/login`）。桌面使用本地 Three.js 渲染粒子地球、模型图标、曲面网格与轨道；地球上下拖拽跟手，背景有鼠标视差、局部反馈和轨道高亮。标题轮换、作品展映和手机背景视频保留；中央按钮登录，滚轮/上下方向键切换展映。画布列表右下的“当前画布设置”提供“登录首页”入口，原画布仍位于 `/`。

登录交互已按 REA 脚本证据补齐：地球与文字共用周期，模型卡片飞出/停靠/归位，点击可排队展示；滚轮连续切换并吸附，相邻作品、页码和键盘均可导航。弹窗与页面隐藏时暂停，关闭后恢复。来源、测试和保留差异见 [交互重建记录](docs/PIX_INTERACTION_RECONSTRUCTION_2026-10-18.md)。

点击“先逛逛”或登录成功，默认进入新的空白画布，收起右侧助手并展开左下小地图。已有画布保留在列表中；刷新恢复当前画布，不重复新建。直接打开 `/` 继续恢复上次活动画布。

连接点左右两侧均可起拖：落到节点主体直接连接，落到空白继续关联创建；取消不留临时节点。助手中 Enter 发送、Shift+Enter 换行，生成期间原发送按钮可停止当前回复并保留草稿。交互核对与限制见 [TapNow 重建记录](docs/TAPNOW_INTERACTION_RECONSTRUCTION_2026-10-18.md)。

左上项目胶囊现在直接展开可搜索的本地画布列表，展示真实缩略图和当前勾选，支持切换与新建；重命名、保存、导入/导出移到画布设置。旧画布仍保存在此浏览器中。

表单接入现有 `APP_PASSWORD` / `/api/session`：配置访问密码时建立 HttpOnly 会话，本机未设密码时直接进入。没有新增短信、邮箱注册、找回密码或团队账号服务；参考站的模型名称只是视觉展陈，不代表本站已配置相应供应商。视觉验收与差异见 `design-qa.md`，素材来源见 `无限画布/assets/pix/ASSET_SOURCES.md`。

没有密钥也可以编辑、上传、保存和导出项目；生成操作会显示未配置原因。修改 `.env` 后重启服务。环境中已有变量优先于 `.env`。密钥只留在服务器，不提交 Git，不写入前端或项目文件。

## 当前能力

- 主工作台按 TapNow 操作界面对齐：440px 右侧 Agent、双建议卡、紧凑输入框、五个空白画布快捷入口、左侧工具栏和底部视图控制条。点击建议卡只预填，不自动发送；首帧入口一次创建图片、视频和连线，支持整体撤销。对话列表、新建/切换对话、更多操作、面板收起/展开/全屏使用真实本地状态。
- 顶部数字表示本站已配置的可用模型数，不是积分余额；社区入口链接本项目 GitHub。音频入口提供时间线音画合成说明；语音按钮提示使用系统听写，没有新增录音或音频驱动画面生成服务。角色/分镜模板和源码入口移到项目菜单，原有工具保留。

- 无限画布、平移、25%–260% 缩放、适应全部节点。
- 节点增删、拖拽、重命名、多选、复制粘贴、撤销和重做。
- 定向连线；阻止重复和循环。文本沿上游链路汇入提示词，图片从直接上游进入参考图；生成和替换素材后同步更新。
- 图片生成/编辑：服务端按模型读取密钥；参考图只提交一次，按主参考和用户顺序发送。
- 全部十种图片比例映射到明确尺寸，文生图和图生图均传递尺寸；特殊供应商可显式选择 `aspect-ratio` 协议。
- 图片亮度、对比度、饱和度、旋转和镜像。效果会烘焙到下游实际使用的参考图，原节点保留可撤销参数。
- Agent 支持多个本地对话、指定节点上下文和最多 4 张图片输入；回答先显示，点击“加入画布”才创建文本节点。建议卡只填入输入框，发送后调用 Chat Completions；没有联网检索或自动执行画布工具。
- 视频任务独立提交、查询、下载、停止等待和继续查询，不再发送到图片接口。
- 角色、分镜、海报模板可编辑主题、比例、图片节点数量（1–8），支持明确追加到已有画布。
- 完整项目自动保存、重开恢复、导入导出、项目名称和新建项目；导入可撤销；新建保留原画布，可从项目菜单切回。
- 生成历史只记录生成结果；项目持久化保留最近 20 项，支持定位和场景回放。


## Creative OS 体验迁移（2026-10-18）

以实际查看的 TapNow 教程画布作为界面和交互参考，保留本项目的数据与服务端边界：

- 黑色点阵画布、紧凑项目菜单、左侧工具栏、统一 Lucide 图标、按节点选择显示的编辑器；编辑器保持屏幕尺寸并避让视口边缘。
- 新建多个本地画布，通过项目菜单切换，原项目会先保存。
- 触控支持平移、拖动节点和双指缩放；真实手机仍需设备验收。
- `Ctrl+K` 搜索节点，按名称、提示词、正文定位；从节点操作条选择连接目标，或从右连接点拖到左连接点。
- 素材库按图片、视频、音频、3D 筛选并定位；节点操作条提供复制、下载、加入时间线、连接和删除。
- 小地图点击定位、连线显隐、24px 网格吸附；原多选、撤销、重做、模板、保存和导出功能保留。
- 音频支持导入、播放、下载、上游文本合成语音、音色和语速设置；密钥和准确模型配置在服务端。`json-audio` 仅适用于符合本仓库契约的同步音频接口，不代表已接入所有音乐生成服务。
- 时间线支持图片/视频顺序拼接、入点和时长裁剪、音频开始时间与音量、片段排序、预览、16:9/9:16/1:1、实时导出 WebM、编码结果预览及重新加入画布。每条时间线最多 200 段；浏览器导出最长 10 分钟、最大 500MB，需要页面保持前台。WebM 不等于 MP4。
- 3D 片场使用 Three.js WebGL：方体、球体、柱体、人形构图参考、完全内嵌资源且未压缩的 GLB 2.0（32MB 内）、位置/旋转/缩放、颜色、镜头环绕/平移/缩放、FOV、背景和灯光。拍摄生成图片节点并连接来源，继续图生图或视频创作。它是构图工具，不是文本生成 3D 模型服务；不包含骨骼动画、DRACO/KTX 解码或专业时间轴镜头动画。
- 视频输入方式、比例、时长、清晰度和参考图数量由 `/api/config` 返回的真实适配能力驱动。默认 OpenAI 适配器仍只支持单首帧、16:9/9:16、4/8/12 秒、720p；确认供应商 JSON 契约后才配置首尾帧/多参考和其他规格。

文件共享使用可携带素材的 `.canvas.json` 导出；本轮未引入 TapNow 的商标、积分、社区、云端账号或多人同步，也没有把链接当成已实现的在线分享服务。

## 保存与素材

IndexedDB 自动保存节点、连线、提示词、比例、模型、参考图、编辑参数、画布位置、历史、音频参数、时间线、对话和 3D 场景。上传素材和生成结果均内嵌到项目，避免依赖临时链接；导入/导出会验证远程或旧版素材是否可完整读取，失败时明确报错。

- 存储按访问地址隔离：不同端口、域名、浏览器和浏览器配置文件不共享项目。
- “导出”生成 `.canvas.json` 用于备份和迁移；清理浏览器数据会删除本地保存。
- 保存失败、存储不足显示错误；多标签页同时编辑时阻止覆盖更新版本，先导出冲突页面再刷新。
- 导入会等待当前保存并先提交本地存储，失败时保留原工作区；撤销/重做包含节点、项目名称与生成历史。旧版记录无法正常恢复时，可从项目菜单“导出原始备份”，保留原数据后再整理修复。
- 上传单文件不超过 100MB，项目导入不超过 256MB，最多 500 个节点和 3000 条连线。视频和完整历史会消耗较多本地空间。
- 旧版历史可在原浏览器查看；失效的旧 `blob:` 素材无法跨会话重建，需要重新上传。

## 模型配置与兼容范围

配置项见 `.env.example`。服务设置展示配置状态；已配置仅代表密钥和模型 ID 齐备，账户权限、协议和真实请求仍需联调。

| 类型 | 页面 ID | 主要环境变量 |
| --- | --- | --- |
| 图片 | `gemini-3.1-flash-image-preview-4k` | `NANOBANANA_API_KEY`、`NANOBANANA_MODEL` |
| 图片 | `gpt-image-2` | `GPT_IMAGE_2_API_KEY`、`GPT_IMAGE_2_MODEL` |
| 图片 | `midjourney`、`jimeng-ai` | `MIDJOURNEY_*`、`JIMENG_*` |
| Agent / 文本 | `gemini`、`chatgpt`、`deepseek` | `AGENT_API_KEY`、各品牌 `*_MODEL` |
| 视频 | `seedance`、`keling` | `VIDEO_API_KEY`、`SEEDANCE_MODEL` / `KLING_MODEL` |

图片默认调用 OpenAI-compatible `/v1/images/generations`（JSON）与 `/v1/images/edits`（multipart），结果支持 `data[0].url` 或 `data[0].b64_json`。不是每个供应商的每个模型都支持这些端点。原生 Midjourney `/mj` 和原生即梦协议不能直接填进本适配器，只配置供应商明确提供兼容端点的模型。

Agent 使用 `/v1/chat/completions`。页面品牌名不是上游模型 ID，完整 ID 由 `GEMINI_MODEL`、`CHATGPT_MODEL`、`DEEPSEEK_MODEL` 映射。每个品牌可独立设置 `*_API_KEY`、`*_API_BASE`。

视频支持两种明确协议：

- `openai`：multipart `POST /v1/videos`，字段为 `model`、`prompt`、`seconds`、`size`、可选 `input_reference`；`GET /v1/videos/{id}` 查询，完成后下载 `/content`。
- `json-task`：JSON 提交 `model`、`prompt`、`aspect_ratio`、`duration`、`images`；默认路径 `/v1/video/generations`，查询 `/v1/video/generations/{id}`。响应须包含任务 ID、状态和完成后的 URL。可以通过共享或每模型的 `*_CREATE_PATH` / `*_QUERY_PATH` 配置路径，路径配置不会改变请求体结构。

默认 OpenAI 视频支持 16:9 / 9:16、4 / 8 / 12 秒、最多一张首帧；JSON 视频可按 `.env.example` 显式配置其他已确认的能力，须选用支持相应字段契约的供应商模型。任务元数据写入 `.local/video-jobs.json`，服务重启后可继续查询，保留 24 小时；更换访问密码会使原访问范围任务无法继续查询。已保存在浏览器中的生成视频不受影响。

当前接口不提供真实数值参考权重，已移除原先重复提交图片的伪权重控件；主参考和顺序保留。

## 同源代理接口

| 路由 | 行为 |
| --- | --- |
| `GET /api/config` | 配置与会话状态，不返回密钥 |
| `POST /api/session`、`DELETE /api/session` | 密码解锁 / 锁定 |
| `POST /api/images/generations`、`POST /api/images/edits` | 接收 `{model,prompt,ratio,images?}` JSON，由服务端转成上游协议 |
| `POST /api/chat` | 接收 `{model,prompt,context?,images?}`，返回 `{text}` |
| `POST /api/audio` | 接收 `{model,prompt,voice,speed}`，返回内嵌音频 `{url}` |
| `POST /api/videos` | 接收 `{model,prompt,ratio,duration,images?,mode?,resolution?}`，返回本站任务 ID 或结果 |
| `GET /api/videos/{id}` | 查询本站任务，不暴露供应商任务 ID |

参考图使用 PNG/JPEG/WebP data URL。远程生成结果仅允许公开 HTTPS 地址；下载不向其他域名发送上游密钥。图片下载上限 24MB，视频 100MB；下载或超时失败会提示去供应商控制台取回结果。

生成 POST 不自动重试，避免断网/超时后重复提交付费任务。视频查询失败保留任务，可继续查询；无法确认提交是否成功时，应先查看供应商任务记录。

## 访问与部署

默认只监听本机。对外监听必须设置 `APP_PASSWORD`，会话使用 HttpOnly、SameSite=Strict Cookie；包含来源/Host 校验、请求体上限、来源限流、超时、脱敏日志。日志不记录提示词、素材、密钥或完整任务 ID。

HTTPS 反向代理部署时设置准确的 `PUBLIC_ORIGIN`、`HOST=0.0.0.0`、强访问密码和供应商配置。`DATA_DIR` 指向持久目录。页面与 API 必须同源，TLS 由反向代理终止。服务不信任任意 `X-Forwarded-For`，同一反向代理后的用户共享来源限流。

`Dockerfile` 提供单实例容器配置。此服务的访问密码不等于多用户账号系统；没有注册、计费、团队权限或云端项目同步。本次未发布线上。
