# Infinite Canvas AIGC

节点式无限画布 AIGC 工作流原型项目。  
你可以在一个可平移/缩放的画布中创建节点、连线组织流程、管理参考图，并直接发起文生图/图生图生成。

仓库地址：<https://github.com/dcjrcjfc/infinite-canvas-aigc>

## 1. 项目目标

- 用无限画布表达多步骤创作链路（而不是单次 prompt）
- 把“输入、参考图、生成结果”放到同一可视化工作空间里
- 逐步向可产品化的创作工作台演进（UI、交互、稳定性、安全性）

## 2. 当前能力（截至最新 `main`）

### 2.1 画布与节点

- 无限画布平移与缩放
- 节点创建（文本/图片/视频）、拖拽、删除
- 节点间 SVG 连线与联动清理
- 空画布引导层（无节点显示，有节点自动隐藏）

### 2.2 生成与参考图

- 文生图（无参考图）
- 图生图（有参考图时自动走 edits 请求）
- 参考图自动流转（上游节点媒体传递到下游）
- 参考图手动添加与移除
- 生成结果就地更新当前节点（不再自动新建结果节点）

### 2.3 模型与鉴权

- 节点内模型下拉选择（当前支持 `NanoBanana` / `gpt-image-2`）
- 按模型路由不同 API Key
- 模型切换后请求自动带入对应 `model` 和 `Authorization`

### 2.4 交互与 UI

- 普通滚轮：画布平移
- `Ctrl + 滚轮`：画布缩放
- 缩放中心漂移修复（避免放大后目标“跑丢”）
- 左侧工具栏（添加/居中/重置/Agent）
- 右侧 Agent 面板（可关闭）
- 右下角 Agent 小球入口（关闭后再打开）

## 3. 技术栈与架构

纯前端项目，无构建工具依赖：

- `HTML`：结构层
- `CSS`：样式与动效
- `Vanilla JavaScript`：交互与业务逻辑
- 浏览器 `fetch`：直接调用图像生成 API

分层约束（开发时必须遵守）：

- `index.html` 只放 DOM 结构和资源引用
- `style.css` 只放样式
- `script.js` 只放行为逻辑

## 5. 本地运行

### 方式 A：直接打开

直接打开 `无限画布/index.html` 即可运行。

### 方式 B：静态服务（推荐）

用任意静态服务器托管项目根目录，避免浏览器部分本地文件限制。

## 6. API 配置说明

当前在 `无限画布/script.js` 中通过常量配置 API Key（前端明文）：

- `T8STAR_API_KEY`
- `GPT_IMAGE_2_API_KEY`

当前模型与 Key 的映射在 `getApiKeyByModel(modelId)` 中维护。  
新增模型时建议同步更新：

1. `MODEL_OPTIONS`
2. `getApiKeyByModel`
3.（可选）请求参数映射逻辑

## 7. 主要交互速查

- 添加节点：左侧 `+` 按钮 -> 选择节点类型
- 删除节点/连线：选中后按 `Delete` / `Backspace`
- 画布平移：拖动画布空白处或滚轮滚动
- 画布缩放：`Ctrl + 滚轮`
- 模型切换：节点底部模型按钮 -> 下拉选择
- 参考图：
  - 自动：连线后由上游传递
  - 手动：节点参考图区域 `+` 上传

## 8. 已知限制与风险

- 前端明文 API Key 不适合生产环境
- 网络波动会影响 API 请求与 Git 推送
- 模型可用性受平台分组/通道配置影响（无通道会报错）
