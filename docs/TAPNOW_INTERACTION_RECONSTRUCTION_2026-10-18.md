## 本地验证

- `npm test` **83/83**；`npm run check`、`npm run build`、`git diff --check` 通过。新增 11 项行为回归，包括双侧拖线、真实 textarea 命中、空白创建取消/原子撤销、无效投放、重命名、快捷键焦点和 Agent 取消竞态。
- 实际 Edge，独立 `18795` origin：Space 打开创建菜单；重命名 Enter 后 editing=0 并保持 label 焦点；右侧连接点拖到空白打开关联菜单并创建连线；独立图片输出拖到只读文本正文后连线数从 1 变 2，临时连接状态已清理。
- 助手浏览器验证使用本地 `createServer` 注入的可延迟假供应商，没有调用收费服务。Enter 发出请求，按钮变为“停止 Agent 回复”；点击后恢复发送、草稿原样保留、取消任务没有新增回复。JSDOM 另覆盖供应商忽略 abort 的晚到结果。
- 当前 `18787` 用户画布不导入这些测试节点；独立测试服务和脚本在收尾清理。截图和摘要留在 `.local/tapnow-rea-review/`。

## 保留差异

没有把上述有限核对称为完整移植 TapNow。基础分组、网格/连线排版和边缘自动平移已在追加轮次实现；嵌套分组、原站 Dagre 精确坐标、富文本提及选择器、云素材目录、协作权限、积分及供应商服务尚未逐项对齐。现有模型能力仍由本站服务配置决定；语音继续使用已有系统听写入口，回复先由用户确认再加入画布。

用户指定的“登录/先逛逛进入空白画布、助手收起、小地图展开”、原画布保存与登录页删除入口均保持。

## 追加：画布本体

- 静态依据：`qc` 的 `autoPanOnNodeDrag/autoPanOnConnect`；画布多选/分组工具条的 `createGroup/ungroup`、`handleSquareGridLayout/handleTreeLayout`；`bxt` 的有向布局与节点间距。沿用本报告中的两个脚本版本和哈希；这些事实不依赖原站云服务。
- 本地新增 `canvas-navigation.js`：48px 可视边缘带、按距离加速、最高 600px/s/轴、单帧间隔上限 40ms；共享核心渲染，节点反向补偿保持抓取点，连线预览同帧，助手遮挡区不移动。鼠标/单指节点/分组/连线受支持；取消、隐藏和失焦停止。拖线保存守卫仅覆盖真实按键手势，不阻碍松手后的点击连接模式。
- 本地新增 `canvas-layout.js/.css`：多选边框和工具条；分组、取消、标题整体拖动/重命名；六向对齐；按实际节点尺寸网格整理；按有向边拓扑分列整理。排版复用节点坐标、连线与命令栈，不触发生成。
- 每节点 `groupId/groupName` 进入快照及导入校验，复制分组重新映射 ID；删除/恢复重新计算边框，无悬空分组记录。支持一步撤销/重做，不改旧版节点格式版本。
- 右键菜单使用原生 top layer 防止被节点编辑浮层遮挡；支持方向键/Home/End/Escape。Escape 返回可见工具条或画布；原生文本菜单关闭已开的自定义菜单。快捷键尊重输入、控件焦点和 IME。
- 最终验证：97/97 全量回归通过（本轮新增 14 项：导航 8、布局 6），构建/语法/差异检查通过。多选工具条直接由相机坐标计算，不再逐个读取已移动节点的屏幕矩形；0.5/1/2 倍率与两套相机坐标约定均覆盖。
