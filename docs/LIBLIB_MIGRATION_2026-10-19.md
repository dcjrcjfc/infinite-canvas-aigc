| 入口 | 实现 |

| 分镜 / 资源 → 资产库 | 角色、场景、道具等分类；跨画布保存复用；版本与引用次数；旧引用显式更新；独立文件夹/多标签、组合搜索、命名、删除 |
| 分镜 / 资源 → 工作流库 | 选中节点保存相对位置、分组、内部连线与外部输入插槽；复用重映射 ID；一次撤销；说明属性保留 |

| 任务中心 | 选区/分组/全画布按依赖执行；1–3 并发；等待/运行/失败/跳过状态；失败分支阻断；重试仅未完成项；停止等待；刷新不自动提交 |
| 任务中心费用 | 服务配置的每请求估价；未知费用明确标识；已知同币种时预算上限拦截；真实供应商返回的数值用量保留在候选详情 |
| 画布导航 | 适应选区、主内容聚簇、全部节点、返回视图；离屏内部内容降载与媒体暂停、低倍率简化；连接点几何保留 |
| 共享画布 | 服务端持久化、创建/打开共享版本、显式推送/载入；版本冲突保留草稿；7 天只读或编辑邀请、撤销邀请；载入可撤销；令牌哈希存储 |

## 服务与部署边界

- 默认单次出图仍为 1。配置模型前缀的 `*_MAX_OUTPUTS`（1–4）后开放数量；后端验证数量并保留有效结果。
- `*_MASK_EDITING=true` 且模型已配置时开放局部生成，走 OpenAI 兼容 multipart `image` + `mask`。透明像素为重绘区域；需要供应商确实支持此协议。未配置时界面仍可使用真实本地编辑和蒙版导出。
- 本地 2× 是插值放大；扩边是实际 Canvas 像素/透明区域扩展。没有宣称 AI 超分、智能抠图或自动补全质量；这些可通过具备能力的蒙版供应商继续生成。
- `*_PRICE_PER_REQUEST` / `*_PRICE_CURRENCY` 是服务维护者提供的估算，不是实时价格抓取或供应商账单。
- 共享文件存于 `DATA_DIR/shared-projects`（默认 `.local/shared-projects`）。使用当前服务的访问密码身份作为创建者，邀请用于单画布只读/编辑权限。尚无独立用户账户、第三方对象存储、多人光标、逐节点锁或 CRDT 同步；并发修改通过修订检查解决，面板显示远端版本更新，用户显式载入。
- localhost 链接只在本机可访问。没有自动开放网络、部署云服务、修改访问密码、推送 GitHub 或调用收费模型。
- 上传/编辑/生成候选及嵌入式库备份会增加本地存储用量；存储失败沿用原有错误和备份路径。
